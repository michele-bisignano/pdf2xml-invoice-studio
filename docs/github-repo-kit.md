# GitHub Repository Kit: Profis Foreign Invoice XML Generator (TD17)

This kit provides metadata and guidelines for publishing the offline tool to GitHub.

---

## 📋 Repository Details
- **Repository Name**: `profis-foreign-invoice-xml-generator`
- **Description**: *100% offline tool and Python Tkinter GUI / local web app to convert foreign supplier invoices into Agenzia delle Entrate compliant XML files (FPR12, TD17) for Sistemi Profis.*
- **Topics / Tags**: `python`, `tkinter`, `xml-generator`, `fattura-elettronica`, `profis`, `td17`, `sistemi-spa`, `accounting`, `pyinstaller`, `react`, `typescript`, `tailwind`
- **License**: MIT License

---

## 🚀 Quick Execution Guide
1. **Desktop App**: `python3 python_script/generatore_xml.py`
2. **Local Web App**: `python3 start_local.py`
3. **Unit Tests**: `python3 python_script/test_generator.py`
4. **Compile Windows .EXE**: Run `python_script/build_exe.bat` on Windows.
